## 🎯 Flujo de Uso Recomendado

### Rutina Diaria Sugerida:

1. **Al Comenzar el Día** (5 min):
   ```
   → Dashboard
   → 🎯 Qué Estudiar
   → Revisa recomendaciones del día
   → Toma nota de las prioridades altas
   ```

2. **Verificar Racha** (2 min):
   ```
   → 🔥 Mi Racha
   → Verifica si ya estudiaste hoy
   → Motívate con el calendario
   ```

3. **Estudiar según Plan** (30-60 min):
   ```
   → Sigue las recomendaciones
   → Practica los temas débiles
   → Completa el repaso espaciado
   ```

4. **Al Terminar el Día** (5 min):
   ```
   → 🕒 Sesiones
   → Revisa tu sesión de hoy
   → 📜 Historial
   → Verifica tu progreso semanal
   ```

5. **Revisión Semanal** (15 min):
   ```
   → 📈 Progreso Tema
   → Analiza qué temas dominas
   → Identifica áreas de mejora
   → Ajusta tu plan de estudio
   ```

## 🔔 Tips y Trucos

### Para Maximizar tu Aprendizaje:

1. **Usa Qué Estudiar cada mañana**
   - Te ahorra tiempo decidiendo
   - Prioriza lo más importante

2. **Mantén tu racha activa**
   - Aunque sea 15 minutos al día
   - La constancia es clave

3. **Revisa Progreso Tema semanalmente**
   - Identifica patrones
   - Ajusta tu estrategia

4. **Consulta tu Historial antes de exámenes**
   - Ve tu evolución
   - Gana confianza

5. **Usa las Sesiones para trackear tiempo**
   - Asegúrate de estudiar suficiente
   - Equilibra trabajo y descanso

## 🎯 Objetivos Recomendados

### Corto Plazo (1 semana):
- [ ] Mantener racha de 7 días
- [ ] Estudiar 30+ min diarios
- [ ] Completar todas las recomendaciones de alta prioridad

### Medio Plazo (1 mes):
- [ ] Mejorar 3 temas débiles a medio
- [ ] Acumular 15+ horas de estudio
- [ ] Racha de 21-30 días

### Largo Plazo (3 meses):
- [ ] Todos los temas >80%
- [ ] Racha de 60+ días
- [ ] Promedio general >85%

## 🆘 Resolución de Problemas

### "No veo mis datos"
→ Asegúrate de haber completado al menos un cuestionario

### "Las estadísticas no se actualizan"
→ Recarga la página (F5) o cierra y vuelve a abrir

### "Un enlace no funciona"
→ Verifica que estés autenticado y vuelve a intentar

### "No entiendo una métrica"
→ Pasa el cursor sobre los iconos para más info
