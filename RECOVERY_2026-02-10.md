## Plan de reanudación (tras reiniciar)
1) Comprobar estado del repo:

2) Confirmar que compila:
   - `npm run build`
3) Lint profesional (sin “colgarse” por salida masiva):
  - `npm run lint` (solo errores; no imprime warnings)
4) Si quieres ver warnings sin inundar el terminal:
  - `npm run lint:report` (genera `eslint-report.json`)
  - `npm run lint:summary` (top reglas/archivos en consola)
5) Auto-fix:
  - `npm run lint:fix`
6) Volver a validar:
  - `npm run build`

## Nota sobre la sensación de “se queda colgado”
- El bloqueo típico aquí es que `eslint` produce **muchísima salida** y el terminal/VS Code se vuelve lento.
- Por eso la estrategia recomendada es `--format json --output-file ...` y resumir con Node, en vez de imprimir todo.
